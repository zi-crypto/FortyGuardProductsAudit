VERDICT
  - Two independent accounts both authenticate.
  - Per-account endpoints (/heatmaps/?num=0, /activity/user-stats) differ by
    account. GOOD.
  - Shared endpoint /voting/submissions is globally identical. This is a
    shared/poll endpoint, not user-scoped.
  - Object-level read on /heatmaps/{uuid}: non-owner consistently gets 500
    "Domain not found", owner gets 200. Cross-tenant read NOT achieved on
    heatmap objects in this run.
  - **Credits barrier: BROKEN.** The account-id filter is silently ignored;
    every combination returns the same 114B error regardless of account.
    Customers cannot see their real spend in the UI.
  - **X-Account-Id header: CRITICAL BOLA.** The API trusts this header and
    enables cross-tenant data access in BOTH directions. Caller A can read
    B's user-stats, and caller B can read A's user-stats, by simply
    supplying the other account's ID. The effective isolation is far weaker
    than the per-account endpoint differences suggest.
  - No cross-tenant heatmap read was achieved via object IDs, but the X-Account-Id
    header completely bypasses any isolation.
